# WordPop

极轻量 macOS 菜单栏翻译工具：选中英文单词/句子，或悬停片刻后，弹出 **DeepSeek** 译文。

## 特点

- 无 Dock 图标（`LSUIElement`）
- 空闲几乎不采样、不常驻面板；翻译弹窗用完自动消失
- 通过 **辅助功能 API** 读取选区/控件文本（非常驻 OCR，更省内存）
- 翻译调用 DeepSeek API（`https://api.deepseek.com/v1`，默认 `deepseek-chat`）
- macOS 26 及以上玻璃面板使用 20pt 圆角与一致的外层裁切，保留顶部尖角；页脚底部留白为 8pt，面板高度随内容同步调整。
- 每条译后释义可独立朗读，底部喇叭仍朗读整段译文。
- 微软在线神经语音：英文可选美式 Jenny / 英式 Sonia，中文使用晓晓；口音选择会保存。
- 本地查询记录：保存最近 100 条成功翻译，可直接恢复完整结果或清空记录。

## 安装

在线朗读额外需要 [edge-tts](https://github.com/rany2/edge-tts) 客户端（7.3.1 或更新版本），无需额外的 TTS API Key：

```bash
python3 -m pip install --upgrade edge-tts
```

```bash
cd ~/WordPop
./build.sh
mkdir -p ~/Applications
cp -R build/WordPop.app ~/Applications/
open ~/Applications/WordPop.app
```

## 朗读

- 点击释义行右侧的小喇叭，只朗读右侧译后释义，按目标语言发音，不读左侧原文。
- 点击底部小喇叭，朗读完整译文。
- 底部“美式 / 英式”口音按钮或右键菜单“英文朗读口音”均可切换口音；新增按钮及菜单沿用原有宋体 / Times 字体，中文朗读不受英文口音设置影响。
- 采用原生流式解码，首段音频到达后即可起播，不等待整段接收完毕。
- 同一文本、同一音色的成功音频会复用内存缓存，不重复联网；缓存预算为 16 条 / 1MiB，重启后清空。首次获取新文本或新音色仍受网络和微软服务响应影响。
- 点击另一条词语、切换口音、重新翻译或关闭面板时，停止旧的朗读或正在生成的语音。
- 获取新音频时，译后朗读文本会发送到微软 Edge 在线语音服务；音频只保留在内存中，不保存到磁盘。
- 服务不可用或缺少客户端时会显示错误，不会静默退回原来的本机机械音色。

## 查询记录

- 点击翻译面板右上角“查询记录”，或右键菜单栏图标 → “查询记录”，按时间倒序查看已保存的查询。
- 仅记录成功的翻译，保存原文、译文、释义、例句和查询时间；最多保留 100 条。同一原文、同一翻译方向再次查询会更新原记录并移到最前，不重复占位。
- 点击一条记录，直接恢复完整结果，不重新请求翻译服务，也不修改剪贴板。历史结果仍可复制、朗读；点击刷新或切换翻译方向时，使用该记录的原文重新查询。
- 记录保存在本机应用偏好设置中，重启后保留，不额外同步到远程服务；本地记录未加密。
- “清空查询记录…”需确认，清空不可撤销，但不会关闭或清除当前显示的译文。
- 从此版本开始积累记录，更新前未保存的查询无法补回。


## 首次使用

1. 允许 **辅助功能**：系统设置 → 隐私与安全性 → 辅助功能 → 勾选 WordPop  
2. 右键菜单栏「译」→ **设置 API Key**（DeepSeek，见 https://platform.deepseek.com ）  
3. 在任意 App 中**拖选**或**双击**英文 → 自动弹出译文  
4. 悬停约 0.45 秒也会尝试取词（可在菜单关闭）

## 菜单

| 项 | 说明 |
|----|------|
| 暂停/启用 | 临时关闭监听 |
| 查询记录 | 查看最近 100 条成功翻译、恢复完整结果或清空本地记录 |
| 悬停翻译 | 开/关悬停取词 |
| API Key / 模型 | DeepSeek 配置 |
| 隐藏弹窗 | 立刻关掉气泡 |

## 内存说明

任意 AppKit 菜单栏程序在系统上约有 **~12MB** 物理占用下限。WordPop 空闲时只挂状态栏项；网络会话使用 ephemeral 配置、无缓存，面板不常驻。

## 限制

- 部分受保护 App（部分浏览器 PDF、游戏全屏）可能读不到文本  
- 需本机可访问 `api.deepseek.com`  
- 真正的「屏幕 OCR」更重，本工具故意不用，以换取小体积与低内存
